# Arsip dokumentasi lama

Berkas di folder ini dipertahankan sebagai riwayat, bukan panduan menjalankan
atau mengubah FilterIN saat ini. Isi arsip tidak diperbarui mengikuti aplikasi.

| Berkas | Asal | Keterangan |
| --- | --- | --- |
| `PATCH_GUIDE.txt` | Folder utama | Panduan patch lama. Jangan diterapkan ulang tanpa pemeriksaan kode terbaru. |
| `PRD.md` | `memory/PRD.md` | Rancangan dan catatan historis; beberapa bagian mungkin tidak lagi sesuai. |
| `test_result.md` | Folder utama | Catatan/protokol pengujian lama, bukan hasil verifikasi versi saat ini. |

Untuk penggunaan saat ini, lihat `README.md` di folder utama,
`backend/notes.txt`, dan `docs/PETA_FITUR.md`.
